# T-032 — Preparar evidencia de salida R5

**Fase:** R5 · **Depende de:** [T-031](T-031-payroll-delivery.md), validación laboral externa.

## Trabajo
- Reunir evidencia de nómina de piloto, recálculo, prestaciones, utilidades, liquidación, provisión, pago y protección de datos.

## Aceptación y evidencia
- Matriz completa de [criterios R5](../backlog/releases.md), informe del especialista y resultados reproducibles; cualquier pendiente mantiene G5 cerrado.
- Solicitar decisión humana: el PR aprobado no sustituye la autorización de release.

## Flujo obligatorio
Crear una rama nueva `docs/t-032-r5-gate` desde `main`. Al terminar y validar, hacer commit Conventional Commits, push y crear un PR con evidencia; solicitar aprobación a **@acamposve**. No aprobar ni fusionar el propio PR.
