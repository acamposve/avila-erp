# T-002 — Preparar decisiones bloqueantes de R1

**Fase:** 0 · **Depende de:** [T-001](T-001-baseline.md).

## Trabajo
- Preparar opciones, impactos, dueños y evidencia para `DEC-001`, `DEC-003` y `DEC-008`.
- Solicitar resolución a Arquitectura, Operaciones, Seguridad y Legal según corresponda; registrar respuestas y bloqueos sin autoaprobar.

## Aceptación y evidencia
- Cada decisión tiene responsable, opciones, impacto y estado verificable en el [registro de decisiones](../docs/decisions/README.md).
- Si alguna sigue pendiente, se documenta el bloqueo; no se selecciona una alternativa por silencio.

## Flujo obligatorio
Crear una rama nueva `docs/t-002-decisions` desde `main`. Al terminar y validar, hacer commit Conventional Commits, push y crear un PR con evidencia; solicitar aprobación a **@acamposve**. No aprobar ni fusionar el propio PR.
